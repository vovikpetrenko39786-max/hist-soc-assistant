# Настройка BotFather для пилота

## Предлагаемое имя

**Ассистент учителя | Бета**

Username выбирается свободный из доступных, например:

```text
TeacherAssistantPilotBot
HistorySocTeacherBot
UchitelAssistantBot
```

Username Telegram должен быть свободен и обычно оканчивается на `bot`.

## Description

Для `/setdescription`:

> ИИ-ассистент для учителей истории и обществознания. Помогает создавать уроки, проверочные, рабочие листы, домашние задания и материалы для ОГЭ/ЕГЭ. Сейчас проходит тестирование с реальными учителями.

## About

Для `/setabouttext`:

> Уроки, проверочные, рабочие листы, ДЗ и ОГЭ/ЕГЭ — в одном педагогическом ассистенте.

## Команды

Для `/setcommands`:

```text
start - Открыть главное меню
help - Как пользоваться ботом
status - Проверить работу системы
feedback - Оставить отзыв или сообщить об ошибке
whoami - Показать мой Telegram ID
```

## Аватар

На пилоте достаточно простой узнаваемой иконки:
- книга / тетрадь;
- буква «А»;
- подпись «Ассистент учителя»;
- без мелкого текста.

Аватар можно заменить в любой момент — код и библиотека от этого не меняются.
