# Официальная универсальная база программ — 2026/2027

## Назначение

Этот dataset — **глобальный слой продукта**. В нём нет профиля конкретного учителя, школы, класса или ученика.

Источник структуры — действующие федеральные рабочие программы, опубликованные на ЕДСОО.

Файл данных:

`data/official_curriculum_seed_2026_2027.json`

Импорт:

```bash
python -m scripts.import_official_curricula
```

Проверка dataset без подключения к БД:

```bash
python -m scripts.validate_curriculum_dataset
```

### Важно

Статус `reviewed` означает, что **структура текущего seed сверена с ФРП**, но Topic Card ещё не является полностью завершённой.

Для статуса `verified` должны быть дополнительно импортированы и проверены:

- предметные результаты;
- релевантные метапредметные результаты;
- ключевые понятия;
- детальная привязка страниц/разделов учебников;
- экзаменационные связи там, где они нужны.

## Обществознание на уровне ООО

Dataset не создаёт устаревшие текущие курсы обществознания для 6–8 классов. Для 2026/27 глобальный текущий каталог ООО строится вокруг программы 9 класса. Архивные программы могут быть добавлены отдельно со статусом `archive`.

## Принцип честного покрытия

Система обязана различать:

- `detailed_topics_hours` — темы и часы перенесены подробно;
- `partial_detail` — часть курса детализирована;
- `skeleton` — загружен только официальный каркас.

Генератор не должен делать вид, что `skeleton` содержит всю поурочную структуру.

## Что дальше

Следующая версия наполняет не новые таблицы, а **содержание Topic Card**:

1. предметные результаты из ФРП;
2. метапредметные действия, реально связанные с темами;
3. ключевые понятия;
4. детальное тематическое планирование истории;
5. углублённое обществознание 10–11;
6. экзаменационные связи ФИПИ;
7. primary/secondary учебники.
