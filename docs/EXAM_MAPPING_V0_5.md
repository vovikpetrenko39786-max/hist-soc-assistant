# Exam Mapping v0.5

## Статус на 05.10.2026

ФИПИ публикует **проекты** КИМ ЕГЭ и ОГЭ 2027 года, а не утверждённые финальные документы.
Поэтому `exam_models.status = project` и этот статус нельзя автоматически повышать до `final`.

## Что подтверждено официально для 2027

### ЕГЭ. История

- 22 задания вместо 21;
- максимальный первичный балл 43 вместо 42;
- новая позиция 15: работа с историческим источником, проверяющая знания по всеобщей истории;
- позиция 20 (в 2026 — 19) ориентирована на понимание исторических понятий и их использование;
- позиция 22 (в 2026 — 21) — два аргумента по истории России, без материала всеобщей истории, максимум 2 балла.

### ЕГЭ. Обществознание

В официальном плане изменений ФИПИ предмет входит в группу **«Изменений нет»**.
В v0.5 поэтому импортирована кодификаторная сетка официального Навигатора ФИПИ-2026
как `baseline`, но она не помечена финальной 2027 до утверждения документов.

Импортировано 75 позиций: 1.1–1.15, 2.1–2.18, 3.1–3.10, 4.1–4.12, 5.1–5.20.

### ОГЭ. История

- старое задание 21 модели 2026 исключено;
- всего 23 задания;
- максимум 35 баллов;
- точная перенумерация оставшихся линий не выдумывается до разбора проектного архива.

### ОГЭ. Обществознание

- 20 заданий вместо 24;
- максимум 32 балла вместо 37;
- изменён порядок заданий;
- модель фотоанализа сокращена до одного дополнительного вопроса/объяснения, максимум 2;
- статистическое задание имеет две модели;
- новая позиция 17: анализ социальной информации, выводы и аргументы;
- заданий с развёрнутым ответом по текстовому источнику стало 3.

Для семейств, номер которых официальный план изменений не называет, поле `task_number` оставлено `null`.

## Новая модель данных

- `exam_models`
- `exam_resources`
- `codifier_elements`
- `exam_tasks`
- `topic_exam_mappings`

Таким образом Topic Card больше не хранит только расплывчатое «эта тема нужна на ЕГЭ».
Она может быть связана с конкретным экзаменом, годом, позицией кодификатора и линией задания с указанием уровня подтверждения.

## Verification statuses

- `confirmed_2027_project_change` — прямо подтверждено официальным документом ФИПИ 2027;
- `official_2026_baseline_carried_forward` — официальный материал 2026, используемый как baseline, поскольку ФИПИ сообщает об отсутствии изменений модели 2027;
- `official_2026_baseline_carried_forward_pending_2027_final` — точная позиция baseline сохранена, но ожидается повторная сверка после утверждения документов 2027;
- `confirmed_family_number_pending` — тип задания подтверждён, но номер не фиксируется без проектного архива;
- `candidate_requires_review` — машинный кандидат; не использовать как установленный факт.

## Topic mapping candidates

`data/topic_exam_candidates_v0_5.json` автоматически предлагает до 3 кодификаторных позиций ЕГЭ обществознания для тем 10–11 классов.
Это **не финальный mapping**. Он нужен для ускорения экспертной сверки.

5. Только после этого позволять генератору писать «задание № N ЕГЭ/ОГЭ-2027» без дополнительной проверки.
