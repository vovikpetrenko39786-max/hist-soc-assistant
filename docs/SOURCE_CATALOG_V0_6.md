# Source Catalog / Textbook Mapping v0.6

## Что добавлено

Универсальный каталог учебников и источников, не привязанный к конкретному учителю.

- 18 source records;
- 17 правил topic→source;
- отдельные source gaps вместо выдуманных соответствий;
- поля ФПУ, ISBN, rollout, verification и availability;
- API source resolver;
- импорт и валидатор.

## Критическое различие

`verified_fpu` означает только подтверждённую библиографическую/нормативную запись. Это **не означает**, что текст PDF уже загружен и доступен RAG.

`availability_status=metadata_only` запрещает модели вести себя так, будто она прочитала учебник. После фактической загрузки разрешённого PDF статус меняется на `file_ingested`, после chunking — на `rag_ready`.

## Источники получения файлов

`origin` и библиографическая сущность разделены. Один и тот же учебник может быть подтверждён ФПУ, а физический файл позднее поступить из официального ресурса, издательства, пользовательской загрузки или разрешённого VK-источника.

VK является каналом получения, а не основанием фактологического авторитета.

## Текущие ограничения

- Региональная история требует выбора региона.
- Для углублённого обществознания 10 класса пока не назначен универсальный основной учебник.
- Для углублённого 11 класса в v0.6 добавлен проверенный источник по социологии/политологии; остальные блоки будут расширены.
- Параграфы и страницы появятся только после импорта конкретных файлов/оглавлений.

## Следующий pipeline

`Source Catalog → file acquisition → checksum → metadata verification → PDF parsing → TOC/paragraph map → chunks → embeddings → topic/chunk mapping → RAG-ready`.
