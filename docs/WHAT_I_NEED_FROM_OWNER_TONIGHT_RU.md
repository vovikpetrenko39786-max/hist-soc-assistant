# Что нужно от владельца проекта для запуска пилота завтра

## Обязательно

### 1. Создать Telegram-бота

Через `@BotFather`.

Результат:
- имя;
- username;
- token.

Token хранится только у владельца в `.env`.

### 2. Подготовить OpenAI API key

Нужен API key именно API Platform.

В `.env`:

```env
OPENAI_API_KEY=...
```

### 3. Выбрать компьютер запуска

Для завтра самый простой вариант:

**ваш компьютер + long polling.**

Условия:
- компьютер включён;
- интернет работает;
- окна backend и bot не закрываются.

Коллеги при этом могут пользоваться ботом со своих телефонов из любого места.

## Желательно

### 4. Решить название

Можно оставить:

**Ассистент учителя | Бета**

### 5. Выбрать круг тестировщиков

На первый пилот лучше 5–15 учителей, а не весь интернет.

### 6. Сказать коллегам одну вещь

> Не пытайтесь пользоваться «правильно». Пользуйтесь как вам удобно. Нам нужны реальные ошибки и неудобства.

## Не требуется

От владельца проекта не требуется:
- писать Python;
- настраивать RAG вручную;
- редактировать базу SQL;
- вручную связывать Telegram с каждой книгой;
- перезаписывать код после добавления учебника.

Эти процессы должны оставаться техническим слоем проекта.
