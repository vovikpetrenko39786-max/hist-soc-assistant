# PDF Ingestion v0.7

## Цель

Перевести Source Catalog из библиографического каталога в фактическую RAG-библиотеку.

До v0.7 источник мог иметь статус `metadata_only`: система знала название, ФПУ, ISBN и роль учебника, но **не имела права утверждать, что прочитала файл**.

v0.7 добавляет воспроизводимый pipeline:

`metadata_only -> file_received -> validated -> text_extracted -> chunked_embedding_pending -> rag_ready`

`rag_ready` будет выставляться только после следующего embedding-этапа. В v0.7 автоматически ставить его запрещено.

## Состояние скана

Если в PDF недостаточно извлекаемого текста:

`needs_ocr`

OCR не запускается автоматически и не подменяет оригинал. Оригинальный PDF сохраняется как первичный файл.

## Новые сущности

### SourcePage

Хранит каждую PDF-страницу отдельно:

- `page_number_pdf` - 1-based номер страницы PDF;
- `page_label` - встроенная PDF-метка, если она есть;
- `printed_page` - только если PDF-метка однозначно задаёт числовую печатную страницу;
- извлечённый текст;
- hash текста;
- способ извлечения.

Система **не угадывает печатную страницу по колонтитулу**.

### SourceSection

Оглавление/закладки PDF:

- уровень;
- заголовок;
- начало/конец в PDF;
- иерархическая связь.

Если в PDF нет структурированного TOC, система не придумывает главы автоматически на этом этапе.

### SourceIngestionRun

Аудит каждого импорта:

- какой файл пришёл;
- SHA-256;
- количество страниц;
- сколько страниц имеют текст;
- число sections/chunks;
- нужен ли OCR;
- ошибка, если импорт не завершён.

## Дедупликация

SHA-256 является главным техническим идентификатором содержимого файла.

Если идентичный PDF уже прикреплён к другому Source, API возвращает `409` и ID существующего источника. Файл не дублируется молча.

## Chunking

Chunk строится только из реально извлечённого текста и сохраняет:

- PDF page start/end;
- printed page start/end, только если известно;
- section ID при наличии PDF TOC;
- text hash;
- `embedding_status=pending`.

## API

### Загрузить PDF

`POST /api/v1/sources/{source_id}/ingest`

multipart field: `file`

optional query: `replace=true`

### Проверить статус

`GET /api/v1/sources/{source_id}/ingestion-status`

## Правило точной страницы

Будущий strict-source запрос:

> На какой странице это написано?

должен ссылаться на `SourcePage`/`SourceChunk`.

Если `printed_page` не установлена, ассистент может назвать PDF-страницу и прямо сказать, что печатная нумерация не определена.

## Что ещё НЕ сделано

v0.7 намеренно не делает:

- OCR;
- embeddings;
- hybrid search;
- автоматическое распознавание параграфов по визуальному оформлению;
- скачивание PDF по URL;
- автоматическое скачивание из VK.

Это отдельные этапы, чтобы ingestion оставался проверяемым и не создавал ложных данных.
